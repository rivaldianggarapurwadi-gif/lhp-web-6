# HER:AI — Women's Health Navigation System (prototype)

Prototype booth untuk gagasan inovasi digital women's health bersama FK Unpad.
Bukan layanan resmi Unpad dan bukan alat diagnosis. Tidak ada data yang disimpan.

Fitur: Cek Gejala (kuesioner), Tanya HER:AI (jawaban dari basis pengetahuan), Navigasi Layanan Unpad.

## Jalankan lokal

```bash
npm start   # http://localhost:3000
```

## Deploy ke Railway

New Project → Deploy from GitHub repo → pilih repo ini dan branch `herai-prototype`,
lalu di Settings set **Root Directory** = `herai-prototype`. Railway menjalankan `npm start`.
Settings → Networking → Generate Domain untuk mendapatkan link publik.
