Cara token dipakai

Token tidak langsung terpotong saat memilih mode token. Token baru terpakai ketika kamu pertama kali menggunakan fitur AI pada dokumen itu, dan kamu akan diminta konfirmasi dulu. Satu token berlaku sampai dokumen diunduh. Kalau layanan AI gagal, token dikembalikan otomatis. Saat token habis, kamu mendapat 1 token gratis setiap minggu.
